# IOT-atividade-3

Discente: Felipe Daniel de Mello

Docente: Amanda Paul Dull

Esse repositório serve para a entrega de atividades da matéria de IoT.

Simular no Tinkercad

Enunciado: Ligar LED com o sensor PIR! O projeto vai utilizar um sensor PIR como entrada para ligar um LED como saída. Ao mexer o sensor PIR, o Arduino leva sinas para o LED acender enquanto o sensor detecta movimento.

O Arduino lê o estado do sensor PIR pelo pino 7 Acende o LED pelo *pino 6

##Materiais necessários

Qtd Componente 1 Placa Arduino UNO 1 Cabo USB 1 Protoboard 1 Sensor PIR 1 LED 1 Resistor (200Ω ou 220Ω) — Fios de jumper macho-macho
